# 🎬 Anime Database Management System

A comprehensive database solution designed for anime production companies to efficiently track projects, departments, staff members, production tasks, contracts, and viewer reviews.

---

## 📌 Project Overview

The animation industry relies on meticulous planning and seamless execution. This project provides a robust relational database schema and a Python-based Graphical User Interface (GUI) to streamline operational workflows within an anime production studio.

### Key Functionalities
- **Department & Project Management:** Organize projects by genre, director, scriptwriter, and managing department.
- **Staff Tracking:** Maintain records for animators, voice actors, and production helpers.
- **Production Tasks & Schedules:** Manage production timelines (pre-production, animation, voice recording, post-production) tied to specific episodes.
- **Contract Management:** Track external collaborators, contracts, and payment terms.
- **Viewer Ratings & Reviews:** Log viewer feedback and episode ratings for performance analysis.

## 🛠️ Tech Stack & Implementation Details

- **Database:** MySQL / MariaDB (`animeuchiha.sql`)
- **GUI Application:** Python (`finalproject_GUI.py` & Visual Studio Project)
- **IDE:** Visual Studio Code / Visual Studio (`animeuchiha.sln`)

---

## 📂 Repository Structure

- `animeuchiha.sql` — Database dump file containing table structures and schema definition.
- `finalproject_GUI.py` — Python script for the graphical user interface.
- `animeuchiha/` — Visual Studio project folder containing solution and project files (`animeuchiha.sln`, `animeuchiha.pyproj`, `animeuchiha.py`).
