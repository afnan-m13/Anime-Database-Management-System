A comprehensive database solution designed for anime production companies to efficiently track projects, departments, staff members, production tasks, contracts, and viewer reviews[cite: 1]. 

This project was developed for the **CS2071: Database Systems** course at the **College of Engineering** (Spring 2024) under the supervision of **Dr. Zain Balfagih**[cite: 1].

---

## 📌 Project Overview

The animation industry relies on meticulous planning and seamless execution[cite: 1]. This project provides a robust relational database schema and a Python-based Graphical User Interface (GUI) to streamline operational workflows within an anime production studio[cite: 1].

### Key Functionalities
- **Department & Project Management:** Organize projects by genre, director, scriptwriter, and managing department[cite: 1].
- **Staff Tracking:** Maintain records for animators, voice actors, and production helpers[cite: 1].
- **Production Tasks & Schedules:** Manage production timelines (pre-production, animation, voice recording, post-production) tied to specific episodes[cite: 1].
- **Contract Management:** Track external collaborators, contracts, and payment terms[cite: 1].
- **Viewer Ratings & Reviews:** Log viewer feedback and episode ratings for performance analysis[cite: 1].
